Laporan praktikum
Kegunaan dari elements : Menampilkan struktur kode HTML dan gaya CSS dari halaman web secara real-time. Bagian ini memungkinkan pengguna melihat tata letak, mengubah atribut atau gaya visual secara sementara, serta menganalisis elemen DOM
kegunaan dari console: Menampilkan pesan log, warning (peringatan), dan error saat aplikasi atau skrip berjalan
kegunaan dari network : Memantau, merekam, dan menganalisis seluruh aktivitas pertukaran data (network requests) antara browser dan server, termasuk pemuatan berkas HTML, CSS, JavaScript, media, hingga panggilan API.
pengertian elements: Elemen adalah komponen dasar penyusun halaman web yang terdiri dari tag pembuka, konten di dalamnya, dan tag penutup. Elemen memberi tahu browser bagaimana suatu informasi harus ditampilkan (misalnya sebagai teks, gambar, tombol, atau tabel).
pengertian console: Console adalah panel interaktif pada browser yang berfungsi sebagai media komunikasi antara developer dan sistem JavaScript halaman web. Panel ini mencatat semua aktivitas kode, pesan sistem, hingga potensi masalah (error) saat web dijalankan.
pengertian network: Network adalah panel analisis lalu lintas data pada browser yang mencatat dan menampilkan seluruh aktivitas komunikasi (requests dan responses) antara peramban (client) dan server backend tempat halaman web di-hosting.
